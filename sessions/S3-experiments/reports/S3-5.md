Each persona file has YAML front matter (`name`, `role`, `focus`, `red_flags`,
`scoring_weights`) plus an attack protocol of 8-9 numbered checks. Weights sum to 1.0 over
soundness/presentation/contribution and are documented as attention allocation, not arithmetic.

## How the tool works

`pack --draft X --round 1 --out DIR` renders six `<persona>.PROMPT.md` files. Each contains the
persona and red flags, its attack protocol, the rubric with scale anchors, the exact YAML
output schema, and the draft between `<<<DRAFT-BEGIN:<sha12>>>` / `<<<DRAFT-END:<sha12>>>`
markers with an instruction to treat it as data (prompt-injection defence). It writes
`_MANIFEST.json` with the draft path/sha256 and prompt hashes. It refuses a draft that already
contains the delimiter.

`ingest --dir DIR` parses `<persona>.review.yaml`, validates required fields, integer score
ranges (1-4 / 1-5 / 1-10), decision labels, must_fix structure (`claim` + `evidence_needed`
required), persona/filename agreement and duplicates. Every error names the file and field;
exit code 1; no aggregate is written while any review is invalid. Writes `INGEST.md` and
`_ingest.json`.

`aggregate --dir DIR --out AGGREGATE.md` emits per-persona scores, mean/median overall
(with range/sd), decision distribution, and a deduplicated must-fix list ranked by number of
distinct personas raising it (similarity: `max(token Jaccard, difflib ratio) >= 0.60` with a
shared-content-token guard; alternate wordings preserved under the table). Ends with a
checkbox tracker seed (`MF-1..n`).

`compare --round1 A --round2 B` matches items across rounds by the same similarity and reports
resolved / persisted / new with counts, score deltas per persona, mean/median overall and reject
count. It prints the caveat that resolved != proved: a response letter must attach the change.

## Decisions and limits

- **The tool is an orchestrator, not a reviewer.** No model is called; the doc and the manifest
  say so explicitly. Reviews must be filled by a human or an agent, one persona per pass, or the
  six voices collapse into one.
- **Rubric provenance is marked honestly.** NeurIPS-derived ranges (soundness/presentation/
  contribution 1-4, overall 1-10) and confidence 1-5; `decision` and `must_fix.evidence_needed`
  are labelled local design, not venue fields. The doc says "verify the current form fields
  before submission" and gives only root URLs (neurips.cc, aclrollingreview.org) because deep
  links move and this environment has no network.
- **No area-chair persona.** The meta-review is authored, not simulated, so the authors' own
  judgement is not laundered into a fake authority.
- **Dedupe is a heuristic.** Threshold 0.60 was chosen on hand-checked paraphrase pairs;
  alternate wordings are kept visible so a human can audit merges.
- Not yet run on a real draft: `05_paper/draft/` did not exist during this session. First real
  use: `pack` the intro once S4/S5 produce it, then check whether the six personas actually
  diverge on a real text (if they do not, the prompts need sharpening, not the paper).

## Findings

- Raw agreement po = 0.59; Cohen's kappa = 0.2802 (overall).
- Disagreements = 41/100, all in the direction A=1 / B=0.
- A answerable 62/100; B answerable 21/100; strict-resolver final answerable 56/100.
- Per rung: r1 κ=0.0000 (6 disagreements), r2 κ=0.2991 (9), r3 κ=0.0260 (18), r4 κ=0.1379 (8).
- Resolver sided with A on 35/41 disagreements and with B on 6/41. The resolved share
  (56%) is far above the prior LLM adjudication (5/100, κ=0.1975). This is a
  prompt/model-sensitivity result, not a gold correction; raw responses are preserved
  for audit and the comparison is stated cautiously in `MF-10.md`.

  resume path recovered it with no relabelling.
- After generation, Ollama had unloaded model A, so the first `/api/ps` snapshot lacked its
  `size_vram`; the script now loads each model for provenance before reading `/api/ps`. Final JSON
  has non-null `size_vram` for all three roles.

  lenient labeller, including at least one clearly incorrect "answerable" decision). This is
  disclosed as a limitation; labels were not hand-corrected because the task requires preserving
  raw model judgements.

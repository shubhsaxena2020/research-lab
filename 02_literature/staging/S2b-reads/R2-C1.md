# R2 — C1 slice reads

**Slice under test (C1):** a gate built *only* from retrieval-side features (BM25 score/margin, dense cosine, retriever agreement, rerank score — no generator call, no hidden-state probe), with **two** dev-fitted thresholds (admit / refuse, dead zone between), evaluated held out at **every rung** of a negative-hardness ladder (random / same-entity / same-topic near-miss / premise violation), reporting abstain precision, abstain recall and **false-refusal rate per rung**, plus threshold placement relative to the observed dev feature range.

## Notes

- **No COLLISION and no CLOSE in this batch.** Nothing published constructs the gate from retrieval-side scores only, with two dev-fitted cut points and a dead zone, scored per rung of a negative-hardness ladder.
- The two-threshold *idea* is present twice, always attached to the wrong signal: #1 certifies threshold pairs on branch uncertainty (needs a generator call), #2 splits initiation from escalation using a model-state logit-gap. #4 has the refusal branch but a single threshold.
- **Threshold placement relative to the dev feature range** — the slice's fourth reporting element — is absent from all 8 abstracts; none reports where the operating point sits inside the observed distribution.
- Papers fetched: **none** (all 8 abstracts were sufficient to settle the verdict; no UNKNOWNs).

# R4-C1 — reads against the C1 slice

**Slice under test.** A gate built ONLY from retrieval-side features (BM25 score/margin, dense cosine, retriever agreement, rerank score; no generator call, no hidden-state probe), with TWO separate dev-fitted thresholds (admit / refuse, dead zone between), evaluated held out at EVERY rung of a negative-hardness ladder (random / same-entity / same-topic near-miss / premise violation), reporting abstain precision, abstain recall AND false-refusal rate per rung, plus threshold placement relative to the observed dev feature range.

**Verdict scale.** COLLISION = does that slice. CLOSE = occupies a large part of it (part named). ADJACENT = related but different object. IRRELEVANT = no abstention/answerability concern.

Batch: `S2b-batches/R4-C1.md` (8 candidates, OpenAlex novelty sweep). Read date: 2026-11-03. Evidence = one verbatim sentence from the OpenAlex abstract per paper (plus one Zenodo record fetch each for #1 and #6, which reproduced the same abstract text and added no threshold/evaluation detail). Max 3 fetches allowed; 2 used.

## Notes

- **#1 EGAA** is the only paper that theorises a "hybrid hard/soft decision function", i.e. the closest thing to a dead zone in the batch, but the abstract places hard constraints on authorisation/tenant/safety policy, not on a second retrieval-score cut, and claims no results. If the C1 paper wants a related-work foil for "gate as decision function", this is it — cite for the concept, not for evidence.
- **#6** is the one to keep in the novelty check: it already establishes that a gate can be trained on retrieval scores with domain-similar hard negatives. The defensible delta is the threshold *pair* (dead zone), per-rung held-out evaluation with abstain precision/recall plus false-refusal, and reporting where the thresholds sit in the dev feature range.
- **#3/#4/#7** form a cluster on over-refusal/refusal in prompt and representation space; useful only as the motivating citation that over-refusal is a real failure mode, and as the excluded-alternative baseline class.
- **#2/#5/#8** each have one threshold or one multi-way decision, no ladder; they are the "single operating point" state of the art the two-threshold framing is meant to beat.

**No COLLISION in this batch.** One CLOSE (#6), seven ADJACENT, zero IRRELEVANT.
